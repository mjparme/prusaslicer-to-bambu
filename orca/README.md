# OrcaSlicer G-code (reference only)

These are the **original** Bambu Studio / OrcaSlicer machine G-code scripts for the Bambu Lab A1, exported before conversion to PrusaSlicer syntax.

They are **not used** by the imported `config-a1-*.ini` profiles. The working profiles use the converted scripts in `prusaslicer/` (embedded inline in each `.ini`).

These files are kept here for reference — to compare against the PrusaSlicer versions, trace where a command came from, or look up Orca/Bambu placeholder syntax during future conversions.

| File | Orca script type |
|------|------------------|
| `orca-a1-start.gcode` | Machine start G-code |
| `orca-a1-end.gcode` | Machine end G-code |
| `orca-a1-layer-change.gcode` | Layer change G-code |
| `orca-a1-filament-change.gcode` | Filament change G-code |
| `orca-a1-timelapse.gcode` | Timelapse G-code |
